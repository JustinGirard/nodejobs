# Generic Multi-Transport Clients (Milestone Scaffold)

This directory is the root for language-specific client implementations proposed in:

- https://github.com/Decelium/interactive/issues/145

Layout (initial scaffold):

- `clients/python/` - Python client package/module work
- `clients/javascript/` - JavaScript/TypeScript client work
- `clients/csharp/` - C# client library work

This first scaffold establishes directory ownership and boundaries only.
No runtime behavior, transport code, or command contracts are implemented here yet.
